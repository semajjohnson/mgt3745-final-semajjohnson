Findings:

- **Deviation from the DDR rule, recorded rather than hidden.** This DDR was written *after* the tool was opened, not before. The brief is explicit that a DDR is committed first, and I did not do that here. The reason is ordinary rather than good: this is the project's second delegation, the habit is not established yet, and the work started as a conversation about where ADRs should live rather than as a planned delegation. Destination: this file, and the habit for DDR-003 onward.
- **An unsupported number carried for five weeks.** ADR-002's prose claimed Gate totals of Build 87, Buy 54, Delegate 40. No table in any commit of either repository ever held the per-criterion scores behind them. This was invisible from reading the file, because the sentence reads exactly like a sentence with a table behind it. Destination: `docs/ADR-002.md`, where the reconstruction and its date are now stated under the table.
- **The reconstruction changed the number and not the decision.** Rescored against ADR-001's own anchors, Build came in at 80 rather than 87. Buy and Delegate landed within a few points of the remembered figures, which suggests the original Build score was generous rather than that the whole Gate was invented. Build still wins by 25 points. Destination: `docs/ADR-002.md`.
- **Where the tool's proposal was wrong and I corrected it.** Claude proposed Build scores of 4 on inspectability and 4 on fit to spec. Both were wrong in opposite directions. Fit to spec is a 5: acceptance row A5 asks that every item carry a source name, and the spec's non-goals are about not recommending and not ranking, none of which moving storage violates. Inspectability is a 3, below the 4 ADR-001 gave my hand-written page, because a Worker plus a SQL schema is harder for me to read than three static files I typed myself. The tool's version flattered the architecture on inspectability and undersold it on spec fit. Destination: `docs/ADR-002.md`, Gate table and the paragraphs below it.
- **What I did not delegate.** The four scores carrying the heaviest weight, 16 of 21, are mine, given in answer to direct questions. Claude proposed the remaining two, Cost to start and Cost to maintain, and I accepted them unchanged. That split is recorded here so a reader can tell which numbers came from my judgment and which did not.
